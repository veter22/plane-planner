## ✦ О проекте

**Plané** создан как альтернатива перегруженным системам управления продуктивностью. Интерфейс вдохновлен концепцией цифрового неоморфизма и глассморфизма (*Glassmorphism*) с анимированной световой сценой *Aurora Mesh*. 

Типографика сочетает акцидентную каллиграфию **Parisienne** в логотипе, геометрический расширенный гротеск **Advaken Sans Expanded** в основном интерфейсе и моноширинный **JetBrains Mono** для системных бейджей и дат.

## ⚡ Основные возможности

### 1. Единый список задач (Tasks)
* Быстрое добавление задач по нажатию `Enter`.
* Моментальное переключение статусов и визуальная отметка завершения.
* Фильтрация по проектам и сквозной поиск по ключевым словам.

### 2. Интерактивный календарь (Calendar)
* Полная сетка месяца с подсветкой текущего дня.
* Навигация по месяцам (`←`, `Сегодня`, `→`).
* Создание событий и задач в один клик по ячейке нужного дня.
* Отображение до 3 цветных статусных индикаторов в ячейке дня со счётчиком скрытых событий.

### 3. Канбан-доска (Kanban)
* Три классических потока: **К выполнению**, **В процессе** и **Готово**.
* Быстрое перемещение карточек между статусами стрелками в один клик.
* Автоматический пересчет задач в каждой колонке.

### 4. Редактор заметок и лонгридов (Notes)
* Двухпанельный режим: список документов слева и чистый холст справа.
* Мгновенный превью-апдейт текста без задержек.
* Возможность удаления заметок как из бокового списка, так и прямо из шапки редактора с подтверждением.

### 5. Персональные проекты (Workspaces)
* Разделение потоков задач и заметок (например, *Личное*, *Работа*, *Учеба*).
* Создание кастомных проектов через модальное окно.

### 6. Облачная синхронизация и мульти-авторизация
* **Локальный режим (Offline First):** все данные мгновенно сохраняются в `LocalStorage` и доступны даже без интернета.
* **Вход через Telegram:** авторизация в один клик через официальный Telegram Login Widget бота `@planenner_bot` с криптографической проверкой подписи `HMAC-SHA256`.
* **Вход через Email и пароль:** полноценная регистрация и авторизация со сквозным хэшированием паролей (`crypto.scryptSync`).
* **Безопасная синхронизация:** автоматический фоновый обмен данными с PostgreSQL через сессионный JWT-токен при появлении сети.

## 🛠 Стек технологий

### Frontend
* **HTML5 / CSS3 / Vanilla JavaScript** — максимальная производительность, нулевой overhead и мгновенный TTI (Time to Interactive).
* **Tailwind CSS (Play CDN)** — атомарная стилизация компонентов.
* **Шрифты:** Advaken Sans Expanded (OpenType CFF), Parisienne, JetBrains Mono.
* **PWA API:** Service Worker / Web App Manifest для нативного опыта на мобильных ОС.

### Backend & Cloud
* **Node.js + Express** (ES Modules) — легкий REST API бэкенд, развернутый на [Render.com](https://render.com).
* **PostgreSQL** — бессерверная облачная база данных на [Neon.tech](https://neon.tech) с хранением пользовательского состояния в формате `JSONB`.
* **Безопасность:** JWT (JSON Web Tokens), `crypto.timingSafeEqual`, `scrypt` hashing.

## 📱 Установка на смартфон (PWA)

Plané оптимизирован для работы как автономное приложение на мобильных устройствах без адресной строки браузера:

### iOS (Safari)
1. Откройте сайт `https://veter22.github.io/plane-planner/` в Safari.
2. Нажмите кнопку **«Поделиться»** (иконка со стрелочкой вверх по центру внизу).
3. Прокрутите список вниз и выберите **«На экран "Домой"»**.

### Android (Chrome / Яндекс)
1. Откройте сайт в Chrome.
2. Нажмите на значок трех точек в верхнем правом углу.
3. Выберите пункт **«Установить приложение»** или **«Добавить на главный экран»**.

## 🚀 Локальный запуск и разработка

### Фронтенд
Так как фронтенд не требует сборки (No-Build Architecture):
1. Склонируйте репозиторий:
   ```bash
   git clone https://github.com/veter22/plane-planner.git
   cd plane-planner
   ```
2. Откройте файл `index.html` в любом браузере или запустите локальный сервер (например, через расширение VS Code *Live Server*).

### Бэкенд
Репозиторий бэкенда (`plane-backend`):
1. Установите зависимости:
   ```bash
   npm install
   ```
2. Создайте файл `.env`:
   ```env
   DATABASE_URL=postgresql://user:pass@ep-host.neon.tech/neondb?sslmode=require
   BOT_TOKEN=your_telegram_bot_token
   JWT_SECRET=your_secret_jwt_key
   PORT=3000
   ```
3. Запустите сервер:
   ```bash
   npm start
   ```
